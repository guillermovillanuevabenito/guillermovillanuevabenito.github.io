# Personal website

Built with Jekyll and the [Minimal Mistakes](https://github.com/mmistakes/minimal-mistakes) theme (v4.26.2, copied into this repo: `_layouts/`, `_includes/`, `_sass/`, `assets/js/`), hosted on GitHub Pages.

- Home page: `index.md`. Other pages: `_pages/` (publications, teaching, CV).
- Top menu: `_data/navigation.yml`. Sidebar, links and skin: `_config.yml`.

## How to run?

```
bundle exec jekyll serve --host 0.0.0.0 --livereload
http://localhost:4000/
```
