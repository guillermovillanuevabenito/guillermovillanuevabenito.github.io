# Personal website

Built with Jekyll and the [Minimal Mistakes](https://github.com/mmistakes/minimal-mistakes) theme (loaded via `remote_theme`), hosted on GitHub Pages.

- Projects are posts in `_posts/` (header image under `header.teaser` / `header.overlay_image`).
- Other pages live in `_pages/`; the top menu is `_data/navigation.yml`.
- Change the look with `minimal_mistakes_skin` in `_config.yml`.

## How to run?

```
bundle exec jekyll serve --livereload
http://localhost:4000/
```
